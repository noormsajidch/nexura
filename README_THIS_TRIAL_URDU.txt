NEXURA Trial: To-Do's Today/Overdue vs Diary Future, Table-wide Reports, Premium Fields

- To-Do's: only incomplete tasks whose due date or reminder date is today or earlier.
- Diary / Tasks: all regular tasks, including future planned and completed history.
- Premium Reminders: policy fields include policy no, client, guardian, phone, risk/due, address, sum assured, premium/mode, SR/SM/SSM/AM and channel where saved.
- Blank policy fields are NOT invented; source data must be available in records.
- All visible data tables get extra search-all-visible-columns + CSV + PDF/Print controls; existing controls remain.
- PDF/Print opens browser print dialog; choose Save as PDF. This is not a separate direct-PDF generator.
- Existing task CSV/PDF remain; the task search also covers stored task and assigned staff data.
- Historical data and login are not modified. Backup before deploy.
- Actual mobile browser workflows must be tested. This is a local demo, not production security.
