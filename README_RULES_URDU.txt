NEXURA مستقل UI اصول:
1. ہر ڈیٹا ٹیبل میں Live Search، اس کے نیچے Download CSV اور PDF/Print، ان کے نیچے Filters، پھر Table۔
2. Fields اور Headings کے ساتھ ترتیب والے نمبر نہیں۔
3. پہلے سے موجود handlers محفوظ رکھنے کے لیے controls منتقل کیے گئے ہیں، دوبارہ نہیں بنائے گئے۔
4. موجودہ browser login اور backup data کو تبدیل نہیں کیا گیا۔
5. تمام Tabs/Subtabs پر موبائل عملی ٹیسٹ ضروری ہے۔
